# Ingredient Defaults

Last updated: 2026-09-18

## Units

- Use grams for solids and millilitres for liquids.
- Use degrees Celsius for temperature.
- Use teaspoons or tablespoons only for small practical quantities when weighing is unreasonable. Prefer grams for salt, leavening, and other consequential ingredients when known.
- Preserve an original non-metric quantity when its metric conversion would add false precision. Mark conversion as unresolved or approximate.

## Naming

- Use the ingredient name familiar in Lithuania when possible, while preserving a source-specific name when the distinction matters.
- Clarify fat percentage, flour type, chocolate cocoa percentage, cured-meat type, and similar specifications only when they affect the result.

## Pantry state

This file does not track current pantry inventory. Ingredients available for one cook belong to the conversation unless Danielius explicitly establishes a durable default.

## Salt and seasoning

- Treat salt quantity as consequential and verify suspicious historical values before recommending them.
- When saltiness depends strongly on bacon, cured meat, cheese, stock, or another salty ingredient, separate base salt from final adjustment.
- "Season to taste" is not a substitute for a useful starting quantity when one is known.
